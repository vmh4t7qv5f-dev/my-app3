# 개발용 가상 회의 음성

앱이 처음부터 끝까지 작동하는지 확인할 때 쓰는 가상 회의 음성이다. 회사와 사람 이름은 모두 지어낸 것이며, 개인정보가 없다.

| 파일 | 내용 |
|---|---|
| `sample-meeting.wav` | 업로드 시험에 쓰는 음성 파일 |
| `sample-meeting.txt` | 음성의 대본 |
| `generate-sample.ps1` | 대본을 음성 파일로 만드는 스크립트 |

Windows에 들어 있는 한국어 음성으로 만들었으므로, 모든 발언의 목소리가 같다.

## 다시 만들기

```bash
powershell -ExecutionPolicy Bypass -File test-audio/generate-sample.ps1
```

## 보고서에 나와야 할 내용

분석 결과를 확인할 때 쓰는 정답이다.

**회의에서 결정된 사항**

- 출시일을 12월 1일에서 12월 15일로 미룬다. (참석자 동의와 정리 발언 있음)
- 단골 고객 50명 대상 시범 운영을 12월 8일에 시작한다. (참석자 찬성과 정리 발언 있음)

**미해결 문제**

- 결제 오류 해결 방법: 원인을 몰라 방법을 정하지 못했다.
- 고객 문의 대응: 한 사람의 일방적 지시에 다른 참석자의 반응이 없었다. "결정"으로 분류되면 오답이다.

**논의된 해결 방안과 장단점**

| 사안 | 방안 | 장점 | 단점 |
|---|---|---|---|
| 출시 일정 | 12월 1일 유지 | 연말 주문을 일찍 받음 | 오류가 남은 채로 나갈 수 있음 |
| 출시 일정 | 2주 연기 | 테스트를 끝낼 시간이 생김 | 연말 홍보 기간이 짧아짐 |
| 결제 오류 | 결제 업체 교체 | 근본적으로 해결될 수 있음 | 계약과 연동에 한 달 정도 걸림 |
| 결제 오류 | 자동 재시도 | 일주일이면 됨 | 원인이 그대로 남음 |

**회의에 나온 수치:** 시험 결제 100건 중 8건 실패, 단골 고객 50명

## 60분 회의 음성

| 파일 | 내용 |
|---|---|
| `meeting-60min.wav` | 59분 30초 길이의 회의 음성. 용량이 커서 커밋하지 않는다 |
| `meeting-60min.txt` | 음성의 대본 (가상 회사 한끼마루, 참석자 5명, 안건 7개) |
| `generate-meeting-60min.mjs`, `generate-meeting-60min.ps1` | 대본을 음성 파일로 만드는 스크립트 |

Windows 한국어 음성 하나의 높낮이를 바꿔 다섯 명처럼 들리게 했다. 다시 만드는 명령은 `node test-audio/generate-meeting-60min.mjs`이다.

**회의에서 결정된 사항**

- 건너뛰기 기능을 1월 20일에 출시하고, 마감은 배송 나흘 전으로 한다.
- 재구독 쿠폰은 시행하지 않는다. (한 번 하기로 했다가 재무 수치를 듣고 뒤집었다. "시행"으로 나오면 오답이다.)
- 3월 1일부터 세트당 2천 원 인상하고, 기존 구독자는 6개월 유예한다. 양을 줄이는 안은 하지 않는다.
- 앱 리뉴얼은 범위를 줄여 메뉴 선택, 주문, 결제 화면을 4월 15일에 출시한다.
- 설 프리미엄 세트를 300개 한정, 7만 9천 원에 1월 11일부터 25일까지 앱에서 판매한다. 기업 단체 주문은 이번에 하지 않는다.

**미해결 문제**

- 메뉴 확대: 개수와 시행 여부 모두 자료가 없어 정하지 못했다.
- 건너뛰기 연속 허용 주 수: 의견이 갈려 정하지 않았다.
- 배송 업체: 위약금과 정식 견적이 없어 정하지 못했다.
- 리뉴얼 테스트 담당: 대표의 일방적 지시에 아무도 답하지 않았다. "결정"으로 분류되면 오답이다.
- 고객 문의 대응(챗봇): "뭐 그럴 수도 있겠죠" 같은 불분명한 반응만 있었다. "결정"으로 분류되면 오답이다.
- 친환경 포장: 필요하다는 이야기만 나왔고 방법과 시험 권역을 정하지 못했다.

**결정으로 나오면 안 되는 잡담:** 점심 김밥 주문, 야구, 날씨
