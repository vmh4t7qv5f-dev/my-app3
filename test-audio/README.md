# 개발용 가상 회의 음성

앱이 처음부터 끝까지 작동하는지 확인할 때 쓰는 가상 회의 음성이다. 회사와 사람 이름은 모두 지어낸 것이며, 개인정보가 없다.

| 파일 | 내용 |
|---|---|
| `sample-meeting.wav` | 업로드 시험에 쓰는 음성 파일 |
| `sample-meeting.txt` | 음성의 대본 |
| `generate-sample.ps1` | 대본을 음성 파일로 만드는 스크립트 |

Windows에 들어 있는 한국어 음성으로 만들었으므로, 모든 발언의 목소리가 같다.

## 다시 만들기

```bash
powershell -ExecutionPolicy Bypass -File test-audio/generate-sample.ps1
```

## 보고서에 나와야 할 내용

분석 결과를 확인할 때 쓰는 정답이다.

**회의에서 결정된 사항**

- 출시일을 12월 1일에서 12월 15일로 미룬다. (참석자 동의와 정리 발언 있음)
- 단골 고객 50명 대상 시범 운영을 12월 8일에 시작한다. (참석자 찬성과 정리 발언 있음)

**미해결 문제**

- 결제 오류 해결 방법: 원인을 몰라 방법을 정하지 못했다.
- 고객 문의 대응: 한 사람의 일방적 지시에 다른 참석자의 반응이 없었다. "결정"으로 분류되면 오답이다.

**논의된 해결 방안과 장단점**

| 사안 | 방안 | 장점 | 단점 |
|---|---|---|---|
| 출시 일정 | 12월 1일 유지 | 연말 주문을 일찍 받음 | 오류가 남은 채로 나갈 수 있음 |
| 출시 일정 | 2주 연기 | 테스트를 끝낼 시간이 생김 | 연말 홍보 기간이 짧아짐 |
| 결제 오류 | 결제 업체 교체 | 근본적으로 해결될 수 있음 | 계약과 연동에 한 달 정도 걸림 |
| 결제 오류 | 자동 재시도 | 일주일이면 됨 | 원인이 그대로 남음 |

**회의에 나온 수치:** 시험 결제 100건 중 8건 실패, 단골 고객 50명
